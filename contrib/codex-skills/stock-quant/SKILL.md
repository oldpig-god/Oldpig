# 量化指标与策略研究

使用stock-data已校验的数据包；没有数据包先调用同级stock-data。运行本技能 `scripts/compute.py --bundle <数据目录>`，输出独立quant/，不改raw。公式已经两只A股与原研究案例回归验证，抽为本技能可导入的唯一实现，供stock-research复用。

- MA20/60/120/250、EMA12/26、DEA9、MACD柱2倍、Wilder RSI14、价格收益、250日波动率和样本回撤均写明公式/复权/窗口/实际起止。RSI平盘、全涨、全跌和不足样本须正确处理。详见[量化规范](references/quant-method.md)。
- 比较多个股票先按实际交易日内连接，缺日不填零收益；相关性需给样本数和收益口径，不以价格水平相关性代替收益相关性。
- 前复权价格收益不是严格含息总回报，不假设现金分红自动再投资。总回报需处理真实除息现金、股本事件与税费。历史技术指标不是盈利保证。
- **只有用户明确要求回测才执行**。先约定信号时点、次日成交、标的范围、起止、基准、复权及现金处理、费用和交易限制。读规范中的回测契约；缺关键成交/历史成分/涨跌停或停牌数据时，标为简化或无法可信验证，不能输出伪精确收益。
- 不把当日收盘信号以同一收盘价成交；不把今天的财报、行业成分或幸存者列表带回历史；不因价格触及限价就假定能成交。未实现或未测试的回测能力必须明确说明。

调用例：`$stock-quant 计算五粮液的MA、MACD、RSI和五年最大回撤，说明复权口径，不回测。`
