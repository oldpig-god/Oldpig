# 指标与回测契约

技术指标统一选择单一供应商qfq收盘；当日估值用raw。MA为N个实际交易日SMA；EMA adjust=False；DIF=EMA12−EMA26，DEA=EMA9(DIF)，柱=2(DIF−DEA)。RSI首14个收益涨跌绝对值简单平均，再Wilder递推；无跌有涨=100，无涨有跌=0，全平=50，不足15个价格=缺失。

价格收益pct_change(fill_method=None)，不跨缺失填充；波动率ddof=1×√250并报告有效样本，回撤close/cummax−1，最大回撤只限数据样本。缺250天不宣称250日年化统计稳定。相关性对同口径日收益按日期inner join，重复日期先拒绝。

回测没有默认执行脚本：由明确策略要求确定实现并测试后才能报告完成。A股契约至少包含：真实历史交易日历、交易所/板块/ST及历史适用涨跌停规则、上市初期特殊规则、T+1可卖库存、100股买入整手及卖出余股规则、停牌、涨跌停队列不可成交、佣金最低收费及费率、历史卖出印花税、过户费、滑点、换手和现金分红。费用或规则随时间变化，须用当时官方规则核验；不能套一份现行费率到所有年份。

信号基于截至决策时可得信息，财报用公告日且保守处理披露时刻，交易推迟到下一实际可成交时点。样本外/滚动验证、参数搜索次数、基准总回报、幸存者偏差、退市和历史股票池、流动性容量都要披露。缺历史成分时只能称固定标的回测，不称全市场有效策略。输出逐笔交易、现金/持仓账本、费用分解、净值与回撤，执行资金守恒/T+1/持仓非负/无未来函数测试。
