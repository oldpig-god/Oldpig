# 第二版设计说明

2026-11-10。用户反馈：第一版不好看，需要重新学习设计技能并继续搜寻开源项目。

## 参考与方法

阅读并采用本机 visualize 的 UI mockups 指南，以及 [Anthropic frontend-design](https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md) 的设计方法：先确定产品任务、字体与布局，再实现并看截图修正。本轮仅阅读公开技能，没有安装额外全局技能。

第一版的具体问题：主图被挤到表格下方；导航占宽；层级主要靠英文眉题；数字与标签都偏小；K线只是简单SVG，无法连续缩放和使用指标。

## 布局决策

以“先看价格与趋势，再定位证券和对比”为主流程。主要视图采用图表优先的终端布局；侧边自选始终可操作，底部研究表随任务切换。

```text
窄导航 │ 品牌 / 工作区                         外观 / 演示标记
       │ 四个市场指数摘要
       │ 证券名称 + 价格 + 数据日          │ 自选证券 / 搜索
       │ 日线 / 周线 / 5分钟 + 指标        │ 名称 价格 涨跌
       │                                   │
       │ K线 + 均线 + 成交量               │
       │ ETF比较 / 原始数据 / 数据质量     │
```

放弃复制旧版“表格优先、图表居下”的布局。图表是视觉中心；同时不采用装饰性渐变、英文大写眉题、卡片阴影和大面积红绿。

## 视觉体系

基础亮色：瓷白 #F4F6FA、面板白 #FFFFFF、墨蓝 #182B49、辅助灰 #65738B、研究蓝 #3859C7、边线灰 #E3E9F1。暗色映射至深海蓝层次，并保持同一强调色语义。

字体：中文系统无衬线（优先 PingFang SC / Noto Sans CJK SC），价格与数值采用系统等宽数字特性。正文12—14px，关键价格36px，页面名称18px。辅助标签不小于11px。

形状：壳体和浮层使用较大圆角，工具按钮使用小圆角，表格只用横向分隔线。高亮只表达选择状态或警示。主图内所有字体与网格按主题同步。

## 实际整合

本轮接入 **KLineChart 9.8.12** 的版本固定 UMD 发行包：K线、缩放、十字线、MA、VOL、MACD均交由库处理。该版本已通过npm包元数据和发行类型定义核查，不声称它是最新版本。与第一版手写SVG绘图相比，这是一项实际依赖整合。

Wealthfolio参考其图表主导的层级；Ghostfolio参考比较与风险信息分区；OpenStock参考自选到详情的连续导航。未复制这些AGPL应用代码。Perspective、dlt、GX和FlexLayout仅进入后续技术方案，未宣称运行。

## 验收范围

搜索、证券切换、排序、日/周/分钟切换、MA和MACD开关、缩放复位、底部研究页切换、亮暗主题、小屏、键盘焦点、外部图表加载失败。演示数据始终明确标记，不把样例数值伪装成实时行情。
