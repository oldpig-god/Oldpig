# 滚动近5年范围

按用户最新要求，统一限制为上海日期回溯五个日历年：2026-11-10 当天为 **2021-11-10 至 2026-11-10**。遇到闰日，五年前不存在 2 月 29 日时取 2 月 28 日。日线采集仍等待当天周期最终发布；当前截至前一个已结束交易日。

主采集参数、价格读取、覆盖统计、GitHub CSV 解析和前端日期标签使用同一边界。GitHub 原始文件保留哈希与固定 commit，可能包含窗口前日期，但这些行在读取时排除，不进入当前图表或分析，也不自动合入主库。

已有全市场数据原本从 2025 年起。变更范围后已将日线任务重新排队补采，首次请求完成数由 0 重新累计；“窗口内有记录”不能代替“近5年请求完成”。新上市证券的历史自然短于5年，停牌 / 源缺失仍可能造成空段，不填造记录。

新原始批次以 gzip 保存，哈希覆盖实际归档字节。价格载荷采用带格式标记的 zlib 压缩，读取兼容旧 JSON 文本；去重哈希仍依据规范化 JSON，压缩本身不会产生虚假的价格修订。原始证据 API 可读取两种格式。

新增测试覆盖五个日历年、闰日、上海日期跨日、窗口边界、GitHub 过滤和压缩格式往返。总计 30 项 Python 测试与 21 项浏览器检查通过。最终补采结果将记录在 `v4/coverage-five-years.json`；运行时进度以 `/api/coverage` 为准。
