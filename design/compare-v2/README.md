# 关联研究页面 / 2026-11-14

## GitHub 方案调研

- https://github.com/tremorlabs/tremor ：Apache-2.0，分析组件的层次、图例和明确的数据状态。
- https://github.com/tremorlabs/template-dashboard-oss ：Apache-2.0，紧凑筛选区域与主分析画布。
- https://github.com/shadcn-ui/ui ：MIT，统一表单、焦点反馈、可展开细节的交互。
- https://github.com/apache/echarts ：交互图表方案。本轮保留原有轻量SVG，增加日期读数与键盘滑块；尚未引入ECharts依赖。

以上借鉴信息架构和交互原则，本轮未复制项目组件代码，也未迁移到React或Next.js；无外部CDN、字体或运行时依赖。

## 设计规范

操作型金融研究工作台，精细、克制。保留已发布theme.css色彩及中文字体token：石墨底、蓝色A、金色B；兼容浅色主题。内容上限1440px，760/1150断点，4px间距体系。沿用原生CSS以维持现有技术栈，不新增Tailwind构建依赖。

顺序：选择对象 → 一句话结论 → 相关系数刻度与窗口冲突 → 走势/日期读数 → 滚动相关性/散点 → 折叠指标证据。定义是描述性的，不是交易推荐；同对象、常数收益、缺失、过期、旧缓存必须给出对应判断。

新增煤炭×元件、银行×元件快捷组合，交换A/B，区间按钮，加载状态，首次访问说明。相关系数优先于不便跨波动率比较的协方差，原协方差、矩阵、下载、方法与原始证据保持可访问。

## 验证
