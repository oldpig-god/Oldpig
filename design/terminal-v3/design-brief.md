# 全市场研究终端 V3

实现日期：2026-11-12。延用 FastAPI、原生前端和本地 KLineCharts；没有新增框架与境外运行依赖。

界面采用墨蓝/暖灰双主题、固定侧栏、全局证券搜索、图表优先。主要颜色为背景 #101923、面板 #17222e、文字 #e8edf3、交互蓝 #81a9e8、强调金 #d4ad76。手机使用抽屉导航。

新增 /stocks 全名录研究；旧市场、技术与共振、策略验证和研究档案共用导航。技术页先图表后明细；策略页分四个页签保留所有原报告内容。登录页面同步更新。

技术研究覆盖名录内A股和ETF，使用实际可用原始日线。样本不足、零成交、缺失保持明确状态。研究能力不等于严格回测可用性，也不等于完整五年数据覆盖。

科创板/北交所模拟申报数量规则已区分；现有历史证券状态、官方逐日涨跌停及企业行动账本缺口依然存在，保留 provisional_research 标记。

本地验收：118项Python测试、14项终端浏览器检查和11项真实策略浏览器检查。截图与机器报告在本目录及 design/strategy；云端验收另存 live-validation.json。
