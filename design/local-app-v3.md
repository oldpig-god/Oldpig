# 第三版：可核验的本地数据工作台

2026-11-10。承接前两轮 25 个开源项目的研究，实际使用 AKShare 与 KLineChart，并用 FastAPI 和 SQLite 打通最小可运行链路。当前实现优先验证数据含义、采集稳定性和真实界面交互，未引入尚未需要的重型组件。

## 视觉与交互

深蓝侧栏、浅色工作区与单一蓝色强调；价格提高字号，数据采用等宽数字。上方为数据保存数量与交易状态，中间为主图与股票池，下方为明细及质量证据。深色模式同步调整 Canvas 图表颜色；窄屏改为单列布局、表格容器内横向滚动。

与旧模拟原型相比，删除了无数据依据的市场指数、ETF 折溢价和收益统计。显示明确的行情时间、抓取时间、数据滞后状态与源字段限制。1 分钟图只输入 timestamp / close；MA 只用于日线和 5 分钟 K 线。

## 数据流

浏览器 → 本地 API → SQLite 快照。用户更新或服务内调度 → 串行采集器 → 超时受限的 AKShare 子进程 → 不可覆盖原始 JSON → 规范化 / 隔离 → 价格表与修订表 → 前端刷新。

保留请求参数、源版本、原始响应哈希与批次标识。每个时间点只保留一条当前观测，值变化追加修订。失败、空批次、部分拒绝批次均不推进成功游标；有效部分仍可保留。游标仅表示成功返回边界，不承诺历史完整性。

当前 SDK 的 1 分钟 ETF / 股票接口使用东方财富 trends2；5 分钟使用 kline。分时开盘 0 按缺失字段提示处理，保留有效价格，禁止填造成 K 线。日线盘中请求截止前一天，避免反复拿到未最终发布的当日数据。

## 本轮检查

- 11 项临时数据库测试：价格语义、时间 / OHLC 异常、去重与修订、冲突隔离、游标、休市时效、源失败保留数据、API 输入与批次证据、失败不标记收盘任务完成。
- 17 项真实本地浏览器检查：显示价格与 API 一致、三个周期、证券联动、搜索、筛选、批次证据、未接入资料提示、无外站依赖、手机无页面溢出、无运行时错误。
- 人工检查桌面、深色、手机和分时截图。
- 实际重复抓取 447 条日线，无重复价格版本。
