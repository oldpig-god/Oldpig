# 前端设计：研究工作台

目标是高密度、低噪声、数据可信的研究界面。首期使用 React + TypeScript；TanStack Table 管表格交互，KLineChart 管K线和内置指标，ECharts 管比较与风险图，shadcn/ui 提供基础组件。以上为选型，尚未搭建生产前端。

## 页面与表格优先级

| 优先级 / 页面 | 最重要的表格字段 | 推荐可视化 | 必须支持的操作 |
|---|---|---|---|
| P0 自选行情 | 代码、名称、最新价、涨跌%、量额、行情时间、源、状态 | 小趋势线；板块/指数摘要 | 搜索、排序、固定名称列、选择行联动详情、过期值识别 |
| P0 个股 / ETF 详情 | 日期、OHLCV、复权方式、缺口、来源 | K线+成交量+均线；数据表切换 | 分时/日线、区间缩放、复权切换、悬浮读数、缺口说明 |
| P0 ETF 同类比较 | 跟踪指数、规模、成交额、费率、NAV日期、IOPV时间、折溢价、跟踪差异/误差 | 同基准归一化净值、回撤、小倍数图 | 同指数筛选、最多4只比较、列选择、排序；缺失项显示原因 |
| P0 数据质量中心 | 数据集、最近行情时点、最近成功拉取、覆盖率、缺口、异常、任务状态 | 延迟趋势、按交易日缺口矩阵 | 按严重度筛选、打开异常样本、重试结果可追溯 |

## 信息层次

顶栏：工作区名称、市场、交易状态、全局数据模式（模拟 / 实时 / 延迟 / 历史）。

主区：左侧导航；中间主图及表格；右侧所选证券的来源、时间和异常说明。宽屏保留三列，平板折为两列，手机保留主内容和可横向滚动的完整表格。默认仅展示6—8个核心列，其余通过列选择展开。

行点击必须使详情、图表和来源信息同步，不弹出阻断研究流程的整页窗口。数值更新不自动重排行，用户明确排序或重排时再改变位置。空态、加载、过期、缺失、错误均要有独立表现。

## 视觉规范

- 使用石墨灰 / 浅暖灰的明暗主题，低饱和强调色；红涨绿跌可切换，始终带正负号。
- 等宽数字、右对齐数值列；中文标签与单位分开，金额统一显示元 / 万 / 亿并在导出中保留原单位。
- 强调一个主图，避免首页几十张指标卡。图表坐标、基准和时段始终可见。
- 细分割线、适度留白、紧凑行高；克制使用动效，不做不断闪烁的“实时感”。
- 来源和时点紧邻关键数值；`—`表示缺失，不能显示0；盘后显示“已收盘”而不是全屏过期警报。
- 可键盘操作，可读焦点样式，不依靠颜色独自传达涨跌或错误。

## 预览与正式版的界限

本轮聊天预览采用模拟价格和演示状态，支持证券筛选、选中、涨跌幅排序、行情/ETF对比/数据质量导航、日线/分时视图。它用于评审布局与操作，不连接真实行情、不会后台轮询、也不会发出投资或交易动作。

正式版应从契约接口加载数据；图表/表格/导出共享一份已校验查询结果。第二版已实际使用固定版本 KLineChart 9.8.12 绘图，详见 redesign-v2.md。若后续采用 Lightweight Charts，仍需按该库 README 和 NOTICE 保留署名链接。真实数据API尚待接入。
