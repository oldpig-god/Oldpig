# 策略验证 V1

入口 `/strategy`，本地和 CloudBase 共用计算引擎。每次研究一个沪深主板/创业板普通股票；510300.SH 可单独研究，也作为固定宽基基准。科创板、北交所、当前ST/退市整理及其他ETF明确拒绝，避免把100股和涨跌幅规则错误套用。不同股票分别运行，不组合成投资组合。

## 先读限制：净价格收益，不是完整投资回报

本版已实现交易模拟与验证流程，但现有免费公开源不足以完成严格时点总回报回测：缺少历史ST/退市状态、官方逐日涨跌停价、分红税/送转和到账账本。所有结果固定标记 `provisional_research`，不能据其宣称策略已有效。

腾讯部分后复权采用带现金累积的变换，**调整价/原价的每日比率不是可直接采用的送转比例**。禁止由此创造持仓份额。实际使用：同一腾讯来源的不复权OHLC执行和估值、前复权close计算MA；同时保存前/后/不复权全部原始响应，检查日期、OHLC、成交量和响应哈希。成交数量是真实股数，收益是**扣除费用后的价格收益，不含未核验分红送转**。遗漏分红影响基准，遗漏送转可能严重扭曲收益；复权历史可被数据商修订，冻结快照可重放不等于历史point-in-time数据。

引擎支持冻结输入中显式的 `corporate_actions`：以除权日为键，`split_ratio`、`cash_per_share`（原股数口径）、`payment_date`，必须 `corporate_actions_verified=true`。分红先计应收，到支付日变成可交易现金；送转修改实际股数。没有官方涨跌停价的企业行动日不成交。公开数据适配器**不会伪造这些事件**；第一版网页没有手工导入入口。现金红利字段须由外部核验为税后可得现金，复杂配股、账户适用税率和股权登记日仍需完整事件账本才能推广应用。

## 固定实验设计

- 默认 MA20/60：T收盘短均线大于长均线，目标满仓；否则空仓。T+1开盘执行，可改为T+1收盘。缺失/零成交量日重置预热，信号为null，不发新指令。
- 最长邻域均线 `slow+2` 日统一预热；余下前70%为形成期、后30%为留出期。至少252日形成期、126日留出期。新上市无法满足共同样本时拒绝，不静默缩短。
- 全区间连续模拟；形成、留出各自从初始现金开始，继承历史指标预热，不继承持仓。不能把分段净收益机械相加。
- Walk-forward：252—504日形成窗口，后126日验证（末段至少63日），规则全程冻结不训练、不寻优，窗口间资金独立。报告与留出期重叠，禁止当额外独立证据相加。
- 敏感性：短、长均线各±2，固定3×3共9组，只看形成期；中心比所有邻居高5个百分点时提示孤立峰值。没有提示不代表不存在过拟合。
- 每个账号保存的实验数×9=已保存参数评估次数，含重复，不含失败、其他账号/外部试验。每次查看留出后改参数都新增试验，不能把同一留出数据再次称为未见数据。原样重放不增加试验数。

## 交易和成本

- 至少延迟一个交易日；买入100股整数倍，未持有股票不可卖，日线模型每天最多发生一次目标转换，从结构上保证T+1。
- 普通主板10%、创业板20%、510300为10%为**假定规则**，缺少历史ST/临时豁免，不能断言精确可成交。开盘（或配置收盘）到涨停不买，到跌停不卖。滑点价格超出日内高低或涨跌停范围则拒绝，不夹成有利价格。
- 缺失与零量不可成交，缺失不会填回输入。为得到连续账户估值，仅沿用最近价格，逐日标记 `stale_mark_missing_bar`；波动率可能低估，缺失仍列在质量面板。
- 默认佣金万3、每笔最低5元；滑点万5；股票过户费万0.1（固定假设，不声称完整历史费率）；股票卖出印花税2023-08-28前千1，此后万5，支持固定税率；ETF印花税/过户费0。费用按分四舍五入。无成交额或量单位核验，因此未建模成交量参与率、冲击成本和排队。
- 现金收益0；无风险收益率只用于夏普。期末按市值估值，不强平、不扣未来退出费用。未完成交易不计胜率。
- 买入持有基准使用相同初始资金、日历、执行与费用规则，首次可成交后不再平仓。
- “仓位匹配”使用策略该段事后平均股票市值/净资产作为基准初始投资比例，不再平衡；不是同贝塔/同波动率风险匹配，也不是可以事先实现的交易建议。

## 随机、统计与复现

随机基准：固定留出期已完成交易次数和各自持有交易日长度，随机排列持有期及空仓间隔（stars and bars）；仍经过同一个交易引擎。如果有期末未平仓部分，其起止日固定。仅对实际成交次数、持有期和期末头寸完全匹配的结果报告排名；小于20个匹配样本不报告统计结论。图展示全部随机结果，排名只基于匹配子集。上尾 `(1+随机收益≥策略收益的次数)/(1+匹配样本数)` 仅为描述参照，非正式显著性证明，未进行跨实验多重检验校正。

随机信号单次跑赢完全可能。验收使用已知零收益的平价路径，随机交易扣费后不能盈利；另用固定随机路径和故意窥视未来两天价格的oracle信号，验证其与正常信号明显不同。修改未来价格不能改变过去的账本。

收益累计与年化（252日）、每日净值样本波动（ddof=1）、夏普、卡玛、从初始资本高点计算的最大回撤、双边成交额/平均净资产换手及年化换手、完整往返胜率和平均盈亏比全部报告。分母为0或无完整交易时显示null，不造0。上述全部基于净价格收益，不能替代总回报指标。

实验为单个不可变JSON对象，一次写入成功才返回成功；文件内包含完整输入、来源与原始响应、全部假设、代码SHA256、两个引擎源文件、运行时版本、随机种子、结果哈希。CloudBase路径 `users/<user>/strategy/experiments/<id>.json.gz`，只通过登录会话的用户前缀读取；对象目录分页列举，不使用容易并发丢记录的共享索引。

下载后离线重放：

```bash
python -X utf8 scripts/replay_strategy.py path/to/strategy-record.json
```

Windows同样可用，先按照根目录 `foragent.md` 安装依赖。使用记录对应源文件和Python/依赖版本。引擎版本变化时网页拒绝假称“同版本重放”，保留旧记录；不要盲目执行不可信记录中的源代码。

## 验证与文件

- `tests/test_strategy.py`：日历/缺失、费用手算、100股、次日开/收盘、涨跌停、停牌、未来突变、oracle对照、随机零收益路径、分红应收/送转、复权比率不得制造股数、重放与窗口。
- `tests/test_strategy_api.py`：认证、同源写入、账号隔离、下载/重放、失败不创建记录、哈希/版本检查、凭证不回显。
- `scripts/check_strategy_ui.py`：本地真实行情、档案/重放、图表、手机390px、相邻入口检查，截图与结果保存在 `design/strategy/`。

## 方法依据

- [Backtrader 订单执行文档](https://www.backtrader.com/docu/order-creation-execution/order-creation-execution/)：次根K线执行的因果边界；参考方法，没有复制代码或新增运行依赖。
- [上交所交易规则（2026年修订）](https://www.sse.com.cn/lawandrules/sselawsrules2025/stocks/exchange/c/c_20260424_10816482.shtml)：执行规则参考。当前规则不是五年历史规则库，因此页面显式标明历史状态缺口。
- [税务总局：证券交易印花税减半](https://www.chinatax.gov.cn/chinatax/n810219/n810780/c5211220/content.html)：2023-08-28税率变化。
- [Bailey & López de Prado: Statistical Overfitting and Backtest Performance](https://sdm.lbl.gov/oapapers/ssrn-id2507040-bailey.pdf)：参数试验次数、样本外和过拟合风险。
