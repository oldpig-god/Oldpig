# 通用双对象比较

入口 `/compare`。任意A股/ETF对A股/ETF，以及两组自选证券，均使用同一引擎。每组1—10只，固定等权；煤炭和元件提供各6只代表股的可编辑预设，不声称完整行业成分。元件预设偏PCB，大型煤企占煤炭预设较多。

## 计算与数据

- 腾讯后复权日线，最多近五年；先按交易日历对齐，再计算简单日收益率 `P[t]/P[t-1]-1`，严禁静默填价或跨缺失交易日计算单日收益。
- 固定等权篮子收益是各成员当日收益均值，任何成员缺失则该日整篮子不可用，不临时重新分配权重。两边与510300共同完整日期用于统计。
- 样本协方差使用n−1分母，单位为小数收益率平方；年化显示乘252。2×2矩阵对角线是方差。
- 同时显示Pearson相关性、20/60/120个连续交易日滚动相关性、散点图、近60/126/252交易日对比、年化波动率。
- 对沪深300ETF同期收益作含截距OLS，显示两边残差相关性。这是同期描述，不是样本外预测、行业因果或完整风险因子模型。近常数收益/残差保持空值，避免数值噪声造成虚假相关。
- 可选择全部历史或最近60/126/252/756个日历内交易日；表格同时给出实际有效样本数。至少30个共同有效收益日。滚动图保留缺口，不以“最近60个非缺失观测”跨越停牌拼接。
- 免费源复权价格是收益代理，不是独立核验的税后分红总回报；股票池有当前选择和存续偏差。组合未扣交易成本，不能作为可交易回测结果。重叠/相同成分显式提示。

## 云端与复现

同一应有交易日的公开源证据缓存于私有system/comparison-prices，减少重复请求。每个报告连同冻结输入、原始响应、哈希、规则和代码哈希保存在users/{user}/comparisons，只能由所属账号下载。页面搜索复用现有全市场名录，不向浏览器暴露存储密钥。

本地运行沿用README；报告存储复用LocalStore。下载JSON后，使用相同版本 `app.comparison.compute(record['snapshot'], record['result']['selection'])` 重算，结果应一致。计算固定成分顺序，输出有限数值统一保留12位小数，避免JSON键排序和机器浮点尾差影响逐项复核。快照冻结确保复现，不意味着数据商历史复权数据是point-in-time数据。

测试：tests/test_comparison.py检查已知正负相关、协方差单位、等权组合、缺失与零量、常数残差、冻结重算及非法价格。scripts/check_comparison_ui.py覆盖板块预设、股票对ETF、成分编辑、空输入、下载、深浅主题和手机。
